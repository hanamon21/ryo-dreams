# RYO'S VISION

**夢を、毎日の原動力に。**

20の夢を、いつでも・すぐに・心地よく眺められる個人用Webアプリです。夢をタスク化して管理するのではなく、未来のイメージを思い出すために作っています。

## 主な機能

- **今日の夢**：起動すると選んだ夢が大きく表示される。左右スワイプや矢印で20個を見て、気に入った夢を「今日の夢」に設定できます。選択は変更するまで保存されます。
- **夢一覧**：20個の夢を画像と文章で閲覧。カテゴリーと「★ お気に入り」で絞り込み。
- **夢ボード**：20個の夢がまとまった画像を拡大表示。
- **ホーム画面に追加**：iPhone/Androidでアプリのように開けます。
- **オフライン対応**：一度オンラインで開き画像のキャッシュが完成すれば、通信がない場所でも閲覧できます。

## データの保存

「今日の夢」と「お気に入り」は **このブラウザ・端末内の localStorage** に保存されます。クラウド同期やバックアップ機能は未搭載です。端末やブラウザのデータを消した場合、設定が消える可能性があります。

旧版の ryoFavs（0始まりの配列位置）を、新版の ryoFavsV2（夢ID）に自動変換します。旧データは消去しません。

## ファイル

- index.html：画面
- styles.css：デザイン、スマホ対応
- app.js：20の夢・スワイプ・今日の夢・お気に入り
- images/：既存の20枚＋夢ボード画像
- manifest.json：ホーム画面追加用
- service-worker.js：オフラインキャッシュ

## 開発時の注意

- 20の夢の文章と画像を勝手に書き換えない。
- 最初に夢が見られる導線を最優先にし、毎日の入力を必須にしない。
- 公開リポジトリ・GitHub Pagesなので、このリポジトリの夢リストは閲覧できる状態です。個人情報や秘密の記録をコードに直書きしない。
