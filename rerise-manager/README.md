# RE:RISE Manager v1.8｜登録区分と直紹介者別管理

**公開 GitHub にはアプリ本体のみ**。人物情報は非公開 Google Sheets に保存されます。

- ステータスを6つに変更：アポ前 / ご案内中 / 登録済み（愛用） / 登録済み（ビジネス） / ビジネスメンバー / 見送り。
- 旧「登録済み」データは、登録区分が「愛用」「ビジネス」なら対応するカテゴリーに読み取り時だけ分類。
- 登録区分が未入力の場合は「登録区分未設定」に分類。勝手に分類・上書きしません。未設定の人がいる間だけ確認用タブを表示。
- 旧「活動中」は表示時に「ビジネスメンバー」として扱い、データ移行時の自動上書きはしません。
- 「直紹介者」を新規・登録後・メンバー・美穂面談シート、活動進捗、人物追加フォームで編集可。
- 人物一覧から、直紹介者ごとに表示を絞り込み可能。未設定も表示。直紹介者は従来の「紹介者名」や「担当者」とは別。
- 直紹介者が不明な既存データは未設定のまま。過去データを推測で補完しません。
- v1.7 のクラウド同期、未同期差分保護、競合対応は維持。

**操作:** 「人物一覧」でステータス選択 → 「直紹介者別に表示」で絞り込み。各人物の「活動進捗」または「ゲストシート」下部で直紹介者1名を指定してください。保存バナーでクラウド保存完了を確認。
