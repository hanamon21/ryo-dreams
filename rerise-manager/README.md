# RE:RISE Manager v1.9.1｜Google OAuthクライアントIDを初期設定

公開リポジトリにはアプリ本体のみを配置。個人情報・アクセストークン・OAuthクライアントシークレットは含まない。OAuthウェブクライアントIDは公開用識別子としてアプリ本体に初期設定済み。

- iPhoneで入力欄にフォーカスすると画面が勝手にズームする問題を防ぐため、スマホの入力要素の文字サイズを16px以上に設定。
- 次回アクションの日付に「日付を消す」ボタンを追加。操作は従来の端末保存・Google同期対象。
- セミナー参加履歴の「事業説明会」にはZoom／リアルの開催形式を必須選択として追加。過去の「事業説明」記録は引き継ぎ、形式未登録として表示して後から編集可能。
- 活動の進捗に「ゆりさんに繋ぐ」を追加。チェックを入れた日を初期値として記録し、過去の日付へ修正可能。取り消す際は確認。
- 既存のステータス分類、直紹介者絞り込み、ゲストシート、クラウド同期、ローカル未同期保護と競合確認は維持。
- 既存の人物データは変更していない。新フィールドは各人物を編集した時に増える。

注意：Googleの保存が終わる前にアプリを閉じた場合は端末内の未同期データが残ります。アプリ上の「クラウド保存済み」を確認してください。

## v1.9.1
- Google OAuthウェブクライアントIDを初期値としてコードに設定。別のPC・ブラウザ・新しいスマホでもIDの貼り付け・「設定を保存」操作は不要。
- 既存端末で別の有効なクライアントIDを設定済みの場合、その端末の設定を優先。
- Googleへの接続操作と共有権限は引き続き必要。未同期保護やクラウド保存処理、個人情報の保存方法は変更しない。
- PWAのservice-workerキャッシュを更新して新しいHTMLを取得できるようにした。
